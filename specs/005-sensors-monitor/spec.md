# Feature Specification: 传感器监控 (Sensors Monitor)

**Feature Branch**: `005-sensors-monitor`

**Created**: 2026-07-21

**Status**: Draft

**Input**: User description: "用户可以在应用中查看手机各类传感器的实时数据。传感器列表页展示所有可用传感器及其状态，点击进入单个传感器详情页查看实时波形/数值变化。支持设置传感器采样频率，数据实时刷新，页面卸载自动释放传感器资源。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 传感器列表浏览 (Priority: P1)

用户进入传感器页面，看到设备支持的所有传感器列表。每个传感器项展示名称、图标、当前可用状态。可用的传感器可点击进入详情页，不可用的传感器置灰并标注原因。

**Why this priority**: 传感器列表是功能的入口页面，用户必须先看到有哪些传感器可用，才能进一步查看数据。这是 MVP 的最小基线。

**Independent Test**: 打开传感器页面 → 看到 7 种传感器列表 → 每个传感器显示名称和可用状态 → 不可用传感器置灰不可点击

**Acceptance Scenarios**:

1. **Given** 用户打开传感器列表页面，**When** 设备支持加速度计且可用，**Then** 加速度计项显示为可用状态，图标正常亮起
2. **Given** 用户打开传感器列表页面，**When** 设备不支持光线传感器（如 iOS 设备），**Then** 光线传感器项灰显，标注"该设备不支持"
3. **Given** 传感器列表已加载，**When** 用户点击一个可用传感器，**Then** 页面跳转到该传感器的数据详情页
4. **Given** 传感器列表已加载，**When** 用户点击一个不可用传感器，**Then** 无响应，不会跳转

---

### User Story 2 - 实时数据监控 (Priority: P1)

用户进入传感器详情页，看到该传感器的实时数据。三轴传感器（加速度计/陀螺仪/磁力计）显示 X/Y/Z 三轴动态数值和波形图，标量传感器（气压计/光线传感器）显示单值读数，计步器显示累计步数。用户可以启动和停止数据采集。

**Why this priority**: 实时数据是传感器功能的核心价值，与列表页同为 P1。

**Independent Test**: 从列表点击加速度计 → 进入详情页 → 看到 X/Y/Z 三轴数值持续变化 → 数值随手机移动而改变 → 点击停止后数值定格

**Acceptance Scenarios**:

1. **Given** 用户进入加速度计详情页且采集已启动，**When** 用户倾斜手机，**Then** X/Y/Z 三轴数值实时变化，响应延迟不超过 200ms
2. **Given** 用户进入气压计详情页，**When** 采集进行中，**Then** 显示当前气压值（hPa）和相对高度（m）
3. **Given** 用户在传感器详情页，**When** 用户点击"停止"按钮，**Then** 数据采集停止，屏幕上保留最后一次读数
4. **Given** 用户在传感器详情页，**When** 用户点击"开始"按钮，**Then** 数据采集恢复，数值开始实时更新
5. **Given** 用户在传感器详情页查看实时数据，**When** 传感器数据更新频率较高（每 100ms），**Then** 界面保持流畅，无明显卡顿

---

### User Story 3 - 采样频率调节 (Priority: P2)

用户在传感器详情页可以调整传感器的采样频率。提供预设档位（慢速/标准/快速），切换后数据更新间隔立即生效。

**Why this priority**: 采样频率调节属于高级控制，不影响核心的查看功能，但能提升专业用户的使用体验。

**Independent Test**: 在加速度计详情页 → 切换采样频率为"慢速"→ 观察到数值更新变慢 → 切换为"快速"→ 数值更新变快

**Acceptance Scenarios**:

1. **Given** 用户在传感器详情页，**When** 默认采样频率为"标准"（约 200ms 间隔），**Then** 数据以标准频率更新
2. **Given** 用户在传感器详情页，**When** 用户切换采样频率至"慢速"（约 1000ms），**Then** 数据更新间隔明显变长，适合低功耗场景
3. **Given** 用户在传感器详情页，**When** 用户切换采样频率至"快速"（约 50ms），**Then** 数据更新更加密集，数值变化更平滑，并显示"高频率可能增加耗电"提示

---

### Edge Cases

- 用户快速切换传感器详情页（列表→详情A→返回→详情B），前一页的传感器资源已正确释放
- App 进入后台时，传感器采集自动暂停；返回前台时自动恢复
- 设备突然失去传感器（硬件异常），页面显示错误提示并停止采集
- 计步器在 iOS 上需要运动权限，权限未授予时显示引导
- 光线传感器在 iOS 上不可用，列表页正确标注
- 气压计在部分旧设备上不支持，列表页正确标注

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须展示设备支持的所有传感器列表，每个传感器显示名称、图标和可用状态
- **FR-002**: 系统必须区分传感器的三种状态：可用、该设备不支持、权限未授予
- **FR-003**: 用户必须能够从传感器列表点击可用传感器，进入对应的数据详情页
- **FR-004**: 系统必须在传感器详情页实时展示传感器数据，三轴传感器显示 X/Y/Z 数值，标量传感器显示单值读数
- **FR-005**: 用户必须能够在详情页启动和停止数据采集
- **FR-006**: 系统必须支持传感器采样频率调节，至少提供三种预设档位（慢速/标准/快速）
- **FR-007**: 切换采样频率后，数据更新间隔必须立即生效
- **FR-008**: 系统必须在 App 进入后台时自动暂停传感器采集，返回前台时自动恢复
- **FR-009**: 系统必须在页面卸载时释放传感器资源，停止数据采集
- **FR-010**: 系统必须在传感器不可用时展示明确的文案说明（不支持/无权限）
- **FR-011**: 计步器等需要特殊权限的传感器，权限未授予时必须引导用户授权
- **FR-012**: 传感器列表页必须在进入时自动检测所有传感器的可用性

### Key Entities

- **SensorInfo（传感器信息）**: 代表一个传感器类型及其当前状态，包含传感器名称、传感器类型标识、可用性状态（可用/不支持/无权限）、当前是否正在采集
- **SensorDataPoint（传感器数据点）**: 代表传感器的一次采样数据，包含时间戳、以及根据传感器类型不同的数值字段（三轴值或标量值）
- **SampleRate（采样频率）**: 代表数据采集间隔的预设档位，包含慢速（1000ms）、标准（200ms）、快速（50ms）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户从进入传感器列表页到查看第一个传感器实时数据，操作步骤不超过 3 步
- **SC-002**: 传感器数据从设备运动到屏幕显示的延迟不超过 200ms
- **SC-003**: 支持的 7 种传感器（加速度计/陀螺仪/磁力计/气压计/计步器/光线传感器/设备运动）全部在列表中展示
- **SC-004**: App 进入后台后 1 秒内传感器采集停止，返回前台后 1 秒内恢复
- **SC-005**: 页面卸载后传感器资源 100% 释放，无后台持续耗电
- **SC-006**: 采样频率切换在 200ms 内生效，用户可感知数据更新间隔变化
- **SC-007**: 用户在详情页切换采样频率时，100% 收到高频率耗电提示

## Assumptions

- 用户设备具备常见的运动和环境传感器（加速度计/陀螺仪为基础传感器，绝大多数智能手机均支持）
- 光线传感器仅 Android 设备支持，iOS 设备将在列表中标注为不可用
- 气压计在部分旧设备上不可用，属于正常现象
- 传感器数据的实时显示不需要持久化存储，仅作为当前会话的实时数据展示
- 采样频率采用预设档位模式（不提供自定义毫秒输入），以简化交互
- 传感器详情页通过首页传感器入口进入，入口已存在于菜单列表中
