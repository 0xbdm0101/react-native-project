# Quickstart: 传感器监控 (Sensors Monitor)

**Date**: 2026-07-21

## Prerequisites

- 开发环境已配置（Node.js、Expo CLI、真机或模拟器）
- 真机建议用于测试加速度计/陀螺仪等运动传感器（模拟器无法模拟真实移动）
- 模拟器可测试列表页的传感器可用性检测
- 已安装 `expo-sensors` ~15.0.8（项目中已存在）

## 验证场景

### 场景 1: 传感器列表 — 可用性检测

1. 在首页点击「传感器」入口
2. 进入传感器列表页
3. 看到 7 种传感器列表：加速度计/陀螺仪/磁力计/气压计/计步器/光线传感器/设备运动
4. 真机上大部分传感器显示为"可用"状态
5. iOS 模拟器上光线传感器显示"该设备不支持"

**Expected**: 每种传感器显示名称、图标、可用性状态。不可用传感器置灰。

### 场景 2: 加速度计 — 三轴实时数据

1. 在传感器列表点击「加速度计」
2. 进入详情页，采集自动启动
3. 看到 X/Y/Z 三轴数值持续更新
4. 倾斜/晃动手机，观察数值变化
5. 点击「停止」，数值定格
6. 点击「开始」，数值恢复更新
7. 点击返回，回到列表页

**Expected**: 三轴数据平稳更新，手机移动时数值有明显变化，启停按钮工作正常。

### 场景 3: 气压计 — 标量数据

1. 在传感器列表点击「气压计」（需真机支持）
2. 看到气压值（hPa）和相对高度（m）
3. 数值以标量格式显示（大号数值，非三轴）

**Expected**: 气压值稳定（通常 950-1050 hPa），相对高度随海拔变化。

### 场景 4: 采样频率切换

1. 进入加速度计详情页
2. 默认频率为「标准」（200ms 间隔）
3. 切换到「慢速」→ 观察到数值刷新变慢
4. 切换到「快速」→ 观察到数值刷新变快，出现耗电提示
5. 切换回「标准」

**Expected**: 三档切换即时生效，快速模式显示耗电提示。

### 场景 5: 前后台切换

1. 在加速度计详情页，采集运行中
2. 按 Home 键回到桌面（App 进入后台）
3. 等待几秒后重新打开 App
4. 传感器数据采集自动恢复

**Expected**: 后台暂停、前台恢复，无报错或数据异常。

### 场景 6: 页面卸载

1. 从列表进入加速度计详情页
2. 按返回键回到列表
3. 再次进入陀螺仪详情页
4. 返回列表

**Expected**: 每次进入新传感器，前一个传感器的资源已释放。无控制台错误、无异常发热。

### 场景 7: 计步器权限（iOS）

1. 在传感器列表点击「计步器」
2. 首次使用弹出运动权限请求
3. 点击「允许」→ 进入详情页，显示步数
4. 点击「拒绝」→ 显示权限引导页

**Expected**: 权限流程完整，拒绝后有明确引导。
