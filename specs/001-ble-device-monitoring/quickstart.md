# Quickstart: BLE设备实时监控管理

**Date**: 2026-06-22
**Feature**: 001-ble-device-monitoring

## 快速验证指南

本指南帮助你验证BLE设备管理功能是否正常工作。

## 前置条件

### 环境要求
- Node.js 18+
- Expo CLI
- iOS模拟器或真机 / Android模拟器或真机
- 蓝牙设备（可选，用于真实测试）

### 依赖检查
```bash
# 检查依赖是否安装
npm list react-native-ble-plx

# 如果未安装，执行
npx expo install react-native-ble-plx
```

### 权限配置
确保 `app.json` 中已配置蓝牙权限：
```json
{
  "expo": {
    "plugins": [
      [
        "react-native-ble-plx",
        {
          "isBackgroundEnabled": false,
          "modes": ["central"],
          "bluetoothAlwaysPermission": "允许使用蓝牙连接设备"
        }
      ]
    ]
  }
}
```

## 验证场景

### 场景 1: 蓝牙状态检查

**目标**: 验证蓝牙状态检测功能

**步骤**:
1. 启动应用
2. 进入蓝牙页面
3. 观察蓝牙状态提示

**预期结果**:
- 蓝牙开启: 显示"蓝牙已开启"，无警告
- 蓝牙关闭: 显示"蓝牙已关闭"，提供"去设置"按钮
- 未授权: 显示"请授权蓝牙权限"，提供"去设置"按钮

**验证命令**:
```bash
# 启动开发服务器
npx expo start

# 在模拟器中运行
npx expo run:ios
# 或
npx expo run:android
```

### 场景 2: 设备扫描

**目标**: 验证设备扫描功能

**步骤**:
1. 确保蓝牙已开启
2. 点击"开始扫描"按钮
3. 等待设备列表更新
4. 观察扫描状态

**预期结果**:
- 点击后显示"扫描中..."状态
- 附近BLE设备出现在列表中
- 设备显示名称、ID、信号强度
- 10秒后自动停止扫描

**测试数据**:
- 使用真实BLE设备（如AirPods、蓝牙音箱）
- 或使用BLE模拟器应用

### 场景 3: 设备连接

**目标**: 验证设备连接功能

**步骤**:
1. 扫描到设备后
2. 点击设备的"连接"按钮
3. 等待连接完成
4. 观察状态变化

**预期结果**:
- 点击后显示"连接中..."状态
- 连接成功后自动进入详情页
- 设备卡片显示"已连接"
- 连接失败显示错误提示

**测试设备**:
- AirPods（苹果设备）
- 蓝牙音箱
- BLE传感器

### 场景 4: 数据读取

**目标**: 验证数据读取功能

**步骤**:
1. 连接设备后进入详情页
2. 等待服务发现完成
3. 查看服务和特征值列表
4. 观察数据读取

**预期结果**:
- 显示设备信息（名称、ID、信号强度）
- 显示服务列表（如果有标准服务）
- 显示特征值列表
- 自动读取可读特征值

**测试数据**:
- 设备信息服务 (180A)
- 电池服务 (180F)
- 环境传感服务 (181A)

### 场景 5: 实时监控

**目标**: 验证实时数据更新

**步骤**:
1. 连接支持数据订阅的设备
2. 查看实时数据卡片
3. 点击"订阅更新"按钮
4. 观察数据变化

**预期结果**:
- 显示传感器数据（温度、湿度、电池）
- 数据每10秒自动更新
- RSSI每10秒更新
- 数据变化时UI实时刷新

**测试设备**:
- BLE温湿度传感器
- BLE心率监测器
- BLE电池设备

### 场景 6: 设备断开

**目标**: 验证断开连接功能

**步骤**:
1. 已连接设备状态
2. 点击"断开"按钮
3. 观察状态变化

**预期结果**:
- 点击后断开连接
- 自动返回设备列表
- 设备卡片恢复"连接"按钮
- 清理所有资源

### 场景 7: 自动断开

**目标**: 验证设备自动断开处理

**步骤**:
1. 已连接设备
2. 将设备移出蓝牙范围
3. 或关闭设备电源
4. 观察应用响应

**预期结果**:
- 自动检测断开事件
- 自动返回设备列表
- 显示断开提示
- 清理所有资源

## 故障排除

### 问题 1: 扫描不到设备

**可能原因**:
- 蓝牙未开启
- 权限未授权
- 设备不在范围内

**解决方法**:
1. 检查蓝牙状态
2. 检查权限设置
3. 靠近设备再试

### 问题 2: 连接失败

**可能原因**:
- 设备不可连接
- 信号弱
- 设备已连接其他手机

**解决方法**:
1. 确认设备可连接
2. 靠近设备
3. 断开其他连接

### 问题 3: 数据读取失败

**可能原因**:
- 设备不支持标准服务
- 特征值不可读
- 连接不稳定

**解决方法**:
1. 检查设备规格
2. 查看特征值属性
3. 重新连接设备

### 问题 4: 应用崩溃

**可能原因**:
- 依赖未安装
- 配置错误
- 内存不足

**解决方法**:
1. 检查依赖安装
2. 检查配置文件
3. 重启应用
